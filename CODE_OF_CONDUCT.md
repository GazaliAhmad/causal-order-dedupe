# Code of Conduct

## Our Standard

This project aims to be respectful, practical, and welcoming.

Contributors, users, and maintainers are expected to:

- communicate respectfully and assume good intent where possible
- give feedback about code and behavior, not about personal traits
- be open to correction and willing to clarify misunderstandings
- keep discussions focused on making the project better
- avoid harassment, hostility, discrimination, and personal attacks

## Unacceptable Behavior

The following kinds of behavior are not acceptable in project spaces:

- abusive or insulting language
- harassment or intimidation
- discriminatory remarks
- doxxing or sharing private information without permission
- repeated bad-faith disruption of discussions or review threads

## Scope

This code of conduct applies to:

- GitHub issues
- pull requests and review discussions
- release and support discussions related to this repository

## Reporting

If you experience or observe behavior that violates this code of conduct, open a private maintainer contact path where possible instead of escalating publicly.

If the issue is security-related, use the process described in [SECURITY.md](SECURITY.md).

## Enforcement

Project maintainers may remove, edit, or restrict content and participation that does not align with this code of conduct.

The goal of enforcement is to protect a healthy working environment for the project and its contributors.
